# Подготовка к поездке

Сроки ниже — рекомендуемый рабочий порядок, **не официальные сроки виз/продаж**.
T = дата вылета из Москвы, пока не выбрана. Напоминания автоматически не настроены.

| Этап | Действия | Условие завершения |
|---|---|---|
| Сейчас | Длительность, бюджет, состав и 3 номера уже заданы; выбрать сезонное окно и впечатления | Понятны приоритеты и умеренный темп |
| После появления подходящих рейсов | Сравнить полную стоимость, проверить документы/транзит/оплату | Сопоставлены минимум две схемы перелёта |
| Позже, после утверждения географии и возвращения к отелям | Подобрать жильё на каждую ночь, сравнить отмену | 3 отдельных номера, нет пропущенных ночей, бюджет сходится |
| По официальным срокам подачи | Проверить визовые требования для каждого, документы и сроки | Все участники могут въехать и совершить транзит |
| По окнам продажи операторов | Бронировать необходимые поезда/автобусы/слоты достопримечательностей | Есть стыковки и доступ на обязательные точки |
| T−30…14 дней | Страховка, связь, оплата, багаж, лекарства, карты | Рабочие способы и офлайн-копии |
| T−7…3 дня | Перепроверить часы, новости JoJo/Inari, погоду, рейсы, отели | Уточнены запасные планы |
| T−1 день | Документы, деньги, зарядки, офлайн-план, регистрация где доступна | Каждый знает аэропорт и время встречи |
| В дороге | Проверять уведомления перевозчиков, расходы и состояние группы | План корректируется без потери обязательного |
| После поездки | Свести фактический бюджет и расчёты друзей | Нет неоплаченных общих расходов |
