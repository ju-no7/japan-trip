# Каталог мест

Две обязательные идеи: **Fushimi Inari** и **JoJo-магазин/кафе**.
Магазин и кафе — две карточки одного совместного блока, а не две отдельные поездки.
Список остальных мест можно менять. Кандидат не означает купленный билет.

Длительности — рабочие оценки. Исторические цены из диалога помечены и требуют
проверки: они не подтверждают стоимость осени 2027. Дорога добавляется отдельно.
