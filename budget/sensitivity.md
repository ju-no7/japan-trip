# Чувствительность бюджета

Не прогноз курсов: три условных значения показывают влияние обмена.
Суммы в каждой ячейке: **YEN / RUB**; валюты эквивалентны, их не складывают.
В каждой строке пересчёт сделан по курсу именно этой строки. Округление до целых.

Исходная рабочая смета при базовом курсе: 471 400 YEN / 249 842 RUB (расходы в иенах) и 366 038 YEN / 194 000 RUB (расходы в рублях).

Для сравнения величина изменения показана в YEN по базовому курсу 0,53 RUB/YEN.

После реальных котировок добавить сценарии роста стоимости жилья и авиабилетов.
Сценарии не являются статистическим прогнозом. Считать из исходных валют,
не из уже округлённых отображаемых эквивалентов.
