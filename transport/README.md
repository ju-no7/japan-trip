# Транспорт

> Суммы: YEN / RUB; пересчёт по условному курсу 1 YEN = 0,53 RUB, округление до целых. [Правила](../budget/currency.md).

**Москва → Токио → Кавагутико → Mishima → Киото → Осака → KIX → Москва**.

| Статья | YEN / RUB |
|---|---:|
| Городской транспорт Токио | 2 500–3 500 YEN / 1 325–1 855 RUB |
| Shinjuku → Kawaguchiko | 2 200 YEN / 1 166 RUB |
| Окрестности Kawaguchiko | 1 500–2 500 YEN / 795–1 325 RUB |
| Kawaguchiko → Mishima | 2 500–2 700 YEN / 1 325–1 431 RUB |
| Mishima → Kyoto, синкансэн | 10 800–11 300 YEN / 5 724–5 989 RUB |
| Киото, городской транспорт | 2 500–3 500 YEN / 1 325–1 855 RUB |
| Kyoto → Osaka | 580 YEN / 307 RUB |
| Осака + KIX | 3 000–4 000 YEN / 1 590–2 120 RUB |
| **Арифметическая сумма** | **25 580–30 280 YEN / 13 557–16 048 RUB** |

Источник всех чисел — [диалог](../docs/research/20260826/source_dialogue/dialogue.txt);
актуальные тарифы не подтверждены. На двоих сумма 51 160–60 560 YEN / 27 115–32 097 RUB.
В смете оставлен исходный конверт **60 000–75 000 YEN / 31 800–39 750 RUB на двоих**,
но его достаточность нужно проверить.

**Пробел:** аэропорт прилёта → Токио в таблице явно отсутствует.
После выбора аэропорта добавить отдельную строку и проверить покрытие конвертом.
Не считать запас доказательством того, что все переезды уже оплачены или учтены точно.

JR Pass не выбран. Сравнивать цену действующего пропуска с суммой только тех поездок,
которые он реально покрывает; автобус/метро нельзя автоматически считать включёнными.
