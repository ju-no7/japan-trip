# D03 · Токио: JoJo и Shibuya

Статус: **предложение**. Календарная дата не выбрана. Время — местное в Японии.
Ночь до / после: **Токио / Токио**.

## Порядок дня

**Утро / начало:** Meiji Jingu либо короткий Harajuku по силам; оба только если день остаётся умеренным

**Далее:** Shibuya PARCO: THE★JOJO WORLD + IGGY CAFE, общий блок 2,5–3,5 часа с запасом на кафе и выбор мерча — новая планировочная оценка для фанатов. Shibuya Sky — только при подходящем слоте.

## Ограничения и логистика

JoJo обязателен; ради него сокращать Harajuku и смотровую, а не наоборот. Шопинг имеет [отдельный фонд](../../budget/shopping.md).

Проверить вход JoJo, очередь кафе и слот смотровой. Кафе заменяет приём пищи.

## Запасной план

При непогоде больше времени PARCO; при недоступности JoJo переставить D02/D03 после проверки.

## Деньги и бронирования

Питание — внутри [дневного конверта](../../budget/food.md).
Транспорт — внутри [общей транспортной сметы](../../transport/README.md).
Входы — только выбранные объекты из [бюджета развлечений](../../budget/activities.md).
Проживание относится к ночи после этого дня; на D10 японской ночёвки нет.
Конкретные слоты, тарифы и брони не подтверждены.
