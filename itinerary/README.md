# Маршрут · базовые 10 дней / 9 ночей

**10 дней пребывания подтверждены пользователем.** География, 9 ночей и конкретные даты пока проект. D01 — прилёт в Японию;
D10 — вылет. Время международных перелётов учитывать сверх местного маршрута.
Детальный график с точными отправлениями появится после выбора рейсов и жилья.

Ночи: **Токио 3 + Кавагутико 1 + Киото 3 + Осака 2 = 9**.
Межгород: Токио → Кавагутико → Mishima → Киото → Осака → KIX.
Схема через Mishima пока требует проверки перевозчиков и конкретной стыковки.

## Обязательное и гибкое

JoJo-магазин/кафе — D03; Fushimi Inari — D06.
Остальные точки можно переставлять/убирать. D02/D03 можно поменять местами по билетам/погоде.
Вечера D05/D07 свободны от обязательных бронирований. После насыщенного D06 день D07 спокойный.
JoJo и Akihabara получают время для интересов пары; отели подбираются позже.
