# Полный топ мест-кандидатов

Экспорт для совместного выбора мест. Версия 26.08.2026.

- [Готовый PDF](../../../output/pdf/japan-places-candidates-2027.pdf): 12 страниц.
- [Текст каталога](catalog.md) и [данные](catalog.json) формируются сборщиком.
- [Сборщик](build_candidates.py): ReportLab, кириллические Arial из Windows; курс читает из `budget/assumptions.json`.
- Источник состава: все 31 карточка `places/`; 27 блоков после объединения четырёх связанных пар.
- Рейтинг редакционный, учитывает интересы пары и текущую логистику. Не изменяет утверждённые решения или статусы исходных карточек.
- Цены на двоих, YEN / RUB, исторические ориентиры. Не новая проверка тарифов.

При изменении карточек пересмотреть содержание сборщика. Он проверяет точное совпадение набора файлов, но не синхронизирует их текст автоматически. После сборки обязательны рендер и визуальная проверка страниц.
