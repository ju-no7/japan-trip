# Plan

## Objective

Find 3–5 strong, real evening/night photographs of Kyoto for the Day 05 day-sheet, prioritizing Gion, Pontocho, Yasaka and Higashiyama. Prefer landscape Wikimedia Commons files with verified authorship/license and a direct image URL around 1600 px.

## Selection criteria

- unmistakably evening, dusk or night;
- visually reads as Kyoto rather than a generic traditional street;
- landscape crop suitable for the day-sheet image panel;
- source page exposes author and reusable license;
- direct downloadable image URL can be derived from Wikimedia Commons.

## Method

1. Discover candidates through web search.
2. Open canonical Commons file pages and verify metadata.
3. Rank candidates for visual fit and provide source/download URLs.
4. Synthesize only from persisted checkpoints.
