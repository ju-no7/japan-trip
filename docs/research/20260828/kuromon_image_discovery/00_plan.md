# Plan

## Objective

Find 2–3 high-quality horizontal photographs of Kuromon Ichiba Market in Osaka for a premium travel website, preferring Wikimedia Commons or another source with explicit reusable licensing.

## Selection criteria

- clearly depicts Kuromon Ichiba Market;
- horizontal framing suitable for a wide day-sheet;
- strong light, color, perspective and sense of place;
- sufficient resolution for desktop display;
- verified author and reusable license;
- direct image URL available.

## Method

1. Discover candidates with web search.
2. Verify each canonical source page and licensing metadata.
3. Render and visually inspect the strongest files.
4. Rank candidates using only persisted checkpoints.
