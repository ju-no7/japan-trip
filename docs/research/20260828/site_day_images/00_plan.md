# План подбора изображений для day-sheet

Цель: найти реальные фотографии ключевых мест десятидневного маршрута для локальной v2 сайта.

Критерии:

- визуально соответствуют конкретным местам маршрута;
- подходят для широкого editorial crop;
- имеют стабильный источник и понятные условия повторного использования;
- итоговый набор остаётся компактным: фотографии переиспользуются между днями одного города;
- предпочтение Wikimedia Commons или официальным туристическим медиаресурсам.

Темы поиска:

1. Tokyo + Kawaguchiko: Shinjuku, Asakusa/Senso-ji, Akihabara, Shibuya, Lake Kawaguchiko/Fuji.
2. Kyoto + Osaka: Fushimi Inari, Higashiyama, Arashiyama, Dotonbori, Osaka Castle, Kansai Airport.
