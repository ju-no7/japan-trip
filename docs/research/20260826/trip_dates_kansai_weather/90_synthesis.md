# Температура по фактическим предварительным датам: Кансай

Источник расчётов: сохранённые выдержки JMA в `20_sources.md`. Нормы за 1991-2020, не прогноз на 2027 год. Средние по периоду ниже — арифметическое среднее дневных климатических норм, округлённое до 0,1 C.

| Город и период | Среднесуточная | Средний дневной максимум | Средний ночной минимум |
| --- | --- | --- | --- |
| Киото, 21-24 октября | +17,1 C | +22,1 C | +12,9 C |
| Осака, 24-26 октября | +17,7 C | +21,9 C | +14,2 C |
