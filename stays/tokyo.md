# База · Токио

> Суммы: YEN / RUB; пересчёт по условному курсу 1 YEN = 0,53 RUB, округление до целых. [Правила](../budget/currency.md).

3 ночи: D01–D03. 1 двухместный номер для личного бюджета.
Из диалога: 20 000–27 000 YEN / 10 600–14 310 RUB/ночь, всего 60 000–81 000 YEN / 31 800–42 930 RUB; текущие предложения не проверены.

Кандидаты для **сравнения**, не рекомендация конкретного отеля:
район Shinjuku для выезда к Кавагутико; альтернативный район с удобным
доступом к аэропорту и D02/D03. Не платить за название района без расчёта дороги.

Проверить: трансфер из выбранного аэропорта, путь с чемоданом до автобуса,
реальную площадь/кровать, ночной шум, позднее заселение, хранение вещей.
После выбора сохранить 2–3 сопоставимых предложения и полную стоимость.

## Статус подбора

По просьбе пользователя от 26.08.2026 конкретные отели **пока не подбираем**.
Для группы обязательно 3 отдельных номера по 2 человека; в личной смете только один номер пары пользователя.
Точные требования к кроватям и удобствам уточним позднее.
