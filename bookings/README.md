# Реестр бронирований

**Бронирований и оплат пока нет.** Таблица — очередь задач. Подбор конкретных отелей отложен по просьбе пользователя; B02–B05 сейчас не активный поиск. Для всей группы нужны 3 отдельных номера, ниже показан один оплачиваемый пользователем номер.
Окна продаж не проверены; даты не подставлять по общему правилу «за месяц».

| B01 | Международные перелёты | 2 оплачиваемых, группа 6 | [рейсы](../transport/flights.md) | Не выбраны | Даты, бюджет, документы |

Для реальной брони создать отдельный файл по [шаблону](../templates/booking.md).
Перед оплатой проверить имя/дату, валюту, всю стоимость, отмену, комиссию,
багаж/налоги, доступный способ оплаты и влияние на остальной маршрут.
Покупки выполнять только после отдельного явного согласования.
